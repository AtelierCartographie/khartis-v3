# Keyboard Shortcuts

This appendix lists the main keyboard shortcuts. Use Cmd on macOS and Ctrl on Windows/Linux. When both are indicated, the first applies to macOS and the second to Windows/Linux.

## Global

- Save project: Cmd+S / Ctrl+S
- Export: Cmd+E / Ctrl+E
- Undo: Cmd+Z / Ctrl+Z
- Redo: Shift+Cmd+Z or Cmd+Y / Ctrl+Y
- Select all: Cmd+A / Ctrl+A
- Find: Cmd+F / Ctrl+F

## Panels and dialogs

- Confirm action (forms, editors): Enter
- Cancel/close a dialog or a panel: Escape

## Editing and selection

- Delete selection: Delete or Backspace
- Nudge selection: Arrow keys
- Nudge faster: Shift+Arrow keys

## Navigation and zoom

- Zoom in: + (plus) or Cmd+= / Ctrl+=
- Zoom out: - (minus) or Cmd- / Ctrl-
- Reset zoom/view: Cmd+0 / Ctrl+0

Notes

- Some shortcuts may vary by browser or language. In case of conflict, the browser's native shortcut takes precedence.
- When a feature is not available (for example, no selection), the shortcut has no effect.
