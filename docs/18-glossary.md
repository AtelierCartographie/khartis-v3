# Glossary - Technical and Cartographic Terms

## A

### Aggregation
Process of grouping data according to a common criterion (sum, average, median, etc.) to reduce information granularity.

### Choropleth Analysis
Cartographic representation method using color ranges to represent statistical values in defined geographic areas.

### Attribute
Characteristic or property associated with a geographic entity (population, density, name, etc.).

### Auto-save
Periodic automatic saving of the project to prevent data loss.

## B

### Basemap
Reference map serving as geographic context on which thematic data is overlaid.

### Bivariate
Cartographic representation combining two statistical variables simultaneously, typically through a color matrix.

### BOM (Byte Order Mark)
Invisible character at the beginning of a text file indicating UTF-8 encoding, important for Excel compatibility.

### Bounds
Minimum bounding rectangle containing all geometries in a geospatial dataset [min_lon, min_lat, max_lon, max_lat].

## C

### Centroid
Geometric center point of a shape or set of points.

### Choropleth
Thematic map where regions are colored according to a statistical variable.

### Classification
Method of grouping values into classes for cartographic representation (quantiles, equal intervals, Jenks, etc.).

### Clustering
Automatic grouping of nearby entities to simplify visualization.

### CORS (Cross-Origin Resource Sharing)
Web security mechanism allowing a page to load resources from a different domain.

### CRS (Coordinate Reference System)
Coordinate reference system defining how geographic coordinates are projected onto a plane.

## D

### Data Pipeline
Automated processing chain for data from import to visualization.

### Dataset
Structured set of data with schema, metadata, and statistics.

### Debounce
Technique limiting the frequency of function execution (e.g., auto-save every 30 seconds).

### Delimiter
Character separating columns in a CSV file (comma, semicolon, tab).

### DuckDB
Analytical database embedded in the browser, used for SQL data processing.

## E

### Encoding
Character representation format (UTF-8, ISO-8859-1, etc.).

### EPSG
Coordinate systems database (e.g., EPSG:4326 for WGS84).

### EXIF
Metadata embedded in images (date, author, geolocation).

## F

### Feature
Geographic entity with geometry and attributes in GeoJSON format.

### FeatureCollection
GeoJSON structure containing multiple features.

## G

### GeoJSON
Standard JSON format for representing vector geographic data.

### GeoPackage (.gpkg)
SQLite-based geospatial data format supporting vector and raster.

### Geometry
Geographic shape (point, line, polygon, multi-polygon).

### Graticule
Grid of meridians and parallels on a map.

## H

### Heatmap
Representation of density or intensity through color gradient.

## I

### IndexedDB
Client-side storage API for large amounts of structured data.

### Interpolation
Estimation of values between known data points.

### Isoline
Line connecting points of equal value (contour line, isotherm).

## J

### Jenks (Natural Breaks)
Classification algorithm optimizing natural groupings in data.

### Join
Association of tabular data with geographic entities through a common key.

## K

### Kernel Density
Density estimation method through spatial smoothing.

### KML/KMZ
Google Earth's XML format for geographic data.

## L

### Layer
Information level overlaid on a map (data, annotations, etc.).

### Legend
Cartographic element explaining symbols, colors, and classifications.

### LocalStorage
Persistent web storage for small data (< 10MB).

## M

### Mercator
Cylindrical map projection preserving angles, standard for web maps.

### Metadata
Information describing data (source, date, author, projection, etc.).

### Multipolygon
Geometry composed of multiple polygons.

## N

### Natural Earth
Balanced pseudo-cylindrical projection for world maps.

### Normalization
Standardization of data (formats, units, scales).

### Null Island
Fictional point at (0,0) where the equator and Greenwich meridian intersect.

## O

### Opacity
Transparency level of an element (0 = transparent, 1 = opaque).

### Orchestrator
Coordinating service managing data flow between components.

### Outlier
Data point significantly different from the rest of the sample.

## P

### PapaParse
JavaScript library for efficiently parsing CSV files.

### Projection
Mathematical transformation from spherical coordinates to a plane.

### Proportional Symbols
Symbols whose size varies according to a quantitative value.

## Q

### Quantile
Division of data into intervals containing the same number of observations.

### Query
Structured request to extract specific data.

## R

### Raster
Geographic data in the form of a pixel grid.

### Reprojection
Conversion of coordinates from one projection system to another.

### Robinson
Compromise pseudo-cylindrical projection for world maps.

## S

### Scale
Ratio between distance on the map and real distance.

### Shapefile
ESRI's multi-file vector format (.shp, .shx, .dbf, .prj).

### Simplification
Reduction of the number of points in a geometry while preserving its shape.

### Spatial Index
Data structure optimizing spatial queries.

### SQL (Structured Query Language)
Query language for relational databases.

### SVG (Scalable Vector Graphics)
XML vector image format for the web.

### Symbology
Set of visual rules for representing data.

## T

### Thematic Map
Map representing a specific phenomenon or theme.

### Tile
Square fragment of a map for progressive loading.

### TopoJSON
GeoJSON extension with shared topology to reduce size.

### Topology
Spatial relationships between entities (adjacency, connectivity, inclusion).

### Transform
Modification applied to data (projection, aggregation, calculation).

## U

### UTF-8
Standard Unicode character encoding for the web.

### Union
Spatial operation merging multiple geometries.

## V

### Vector
Geographic data defined by coordinates and attributes (vs raster).

### Viewport
Visible area of the map in the interface.

### Visualization
Graphic representation of data for analysis and communication.

## W

### WebGL
JavaScript API for GPU-accelerated 3D graphics rendering.

### Web Mercator (EPSG:3857)
Mercator projection adapted for interactive web maps.

### WGS84 (EPSG:4326)
World geodetic reference system for GPS.

### WKB (Well-Known Binary)
Standard binary format for geometries.

### WKT (Well-Known Text)
Standard text format for geometries.

### Worker (Web Worker)
Separate JavaScript thread for calculations without blocking the interface.

## Z

### Z-index
Stacking order of layers (higher = on top).

### Zoom
Level of detail display on the map.
